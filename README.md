## 📝 О боте

Бот создан для тех, кто работает с JSON и устал от непонятных сообщений об ошибках. Вместо стрелочек и номеров строк, бот **человеческим языком** объясняет:

- ❌ **Что именно не так** с вашим JSON
- 🔧 **Как это исправить** по шагам
- ✅ **Показывает правильный вариант**

## ✨ Возможности

| Функция | Описание |
|---------|----------|
| 🔍 **Проверка JSON** | Находит синтаксические ошибки |
| 🎨 **Форматирование** | Делает JSON красивым с отступами |
| 📖 **Объяснение ошибок** | Понятно описывает проблему |
| 💡 **Советы по исправлению** | Даёт конкретные рекомендации |
| 📁 **Работа с файлами** | Поддерживает загрузку .json файлов |
| 🔄 **Сортировка ключей** | Упорядочивает поля для удобства |

## 🔎 Примеры работы

#### 1. Правильный JSON

**Отправляете:**
```json
{"name": "Анна", "age": 25, "city": "Москва"}
```

**Бот отвечает:**
✅ JSON ПРАВИЛЬНЫЙ!

Отформатированный вариант:
```json
{
  "name": "Анна",
  "age": 25,
  "city": "Москва"
}
```
#### 2. Ошибка с одинарными кавычками

**Отправляете:**
```json
{'name': 'John', 'age': 30}
```

**Бот отвечает:**
❌ ОШИБКА: Использованы одинарные кавычки

📝 ЧТО НЕ ТАК: В JSON можно использовать только двойные кавычки

🔧 КАК ИСПРАВИТЬ: Замените все одинарные кавычки на двойные

✅ ПРАВИЛЬНО:
```json
{"name": "John", "age": 30}
```

#### 3. Лишняя запятая

**Отправляете:**
```json
{"name": "John", "age": 30,}
```

**Бот отвечает:**
❌ ОШИБКА: Лишняя запятая перед закрывающей скобкой

📝 ЧТО НЕ ТАК: После последнего элемента в объекте не нужна запятая

🔧 КАК ИСПРАВИТЬ: Удалите запятую перед закрывающей скобкой

✅ ПРАВИЛЬНО:
```json
{"name": "John", "age": 30}
```
## ⚙️ Установка и запуск

1. Установите зависимости:
pip install -r requirements.txt

2. Получите токен у @BotFather в Telegram

3. Вставьте токен в файл json_bot.py:
BOT_TOKEN = "ваш_токен"

4. Запустите бота:
python json_bot.py
